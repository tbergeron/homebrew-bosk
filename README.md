# Homebrew tap for Bosk

[Bosk](https://github.com/tbergeron/bosk-browser) is a small, fast, opinionated web browser for macOS.

```bash
brew install --cask tbergeron/bosk/bosk
```

Bosk updates itself (Sparkle). `brew upgrade` also works.
The release script of Bosk updates `Casks/bosk.rb` for each release.
